# Changelog

## Unreleased

### 2026-10-10

- Added the provider-neutral project instructions in `AGENTS.md`.
- Added the durable cross-agent task handoff in `TODO.md`.
- Implemented the Node/TypeScript scaffold, grapheme-aware text partitioning, SQLite sessions/shares, HTTP text/image share APIs, deterministic image allocation, image validation/storage/rendering, and integration tests.
- Closed the Task 3 original-image exposure finding by moving the default data directory outside the Vite root, denying raw storage paths in Vite, and adding a direct static-server regression test. Verified with 31 tests, typecheck, build, and a clean Task 3 re-review. Pushed as commit `9e206c1` to `origin/master`.
- Recorded demo decisions (Vercel hosting, 64-person audience, no `.txt` upload, End share) and lowered the `MAX_RECIPIENTS` default from 256 to 64. Verified with 31 tests and typecheck. Flagged the Vercel vs SQLite/WebSocket conflict as a blocker before Task 4.
- Chose Vercel Functions + Supabase free plan (Postgres, private Storage, Realtime Broadcast) to replace SQLite/`ws`/Docker for hosting; documented in `docs/decisions.md`. No code ported yet.
- Ported the backend off `node:sqlite`/`DATA_DIR`: async SQL layer with a `postgres` adapter (Supabase, transaction pooler) and a PGlite adapter (tests/local dev); joins lock the share row; RLS enabled on all tables; originals stored as lossless PNG in a private Supabase Storage bucket (local disk when unconfigured) with an in-memory decode cache; join publishes `{ revision, status }` via Supabase Realtime Broadcast REST; Vercel entry `api/index.ts`, `vercel.json`, `npm run db:migrate`, `docs/setup.md`; upload default 4 MiB; removed `ws`. Verified with 34 tests, typecheck and server build. `vite build` still fails because `src/web/main.tsx` (Task 5) does not exist yet; the `postgres` adapter is untested against a live database.
- Added End share (`POST /api/shares/:id/end`, creator-only, idempotent, `ended` status, `SHARE_ENDED`/`NOT_CREATOR` errors) and `GET /api/cron/cleanup` (Vercel Cron, `CRON_SECRET`) that deletes ended/expired shares, their stored images and expired sessions. Snapshots now include `maxRecipients`.
- Built the web UI in `src/web/` from the `frontend` branch's Windows XP design (XP window, Bliss background as WebP, DVD logos, shatter transition, taskbar), wired to the real API: Creator page with TEXT/IMAGE input; share page `/s/:id` with live portion (text or collage), URL + QR, End share for recipient #1, Supabase Realtime subscription with polling fallback and revision guard, expiry timer, and closed/offline states. Dev server: UI on 3000, API on 3001. Verified with 37 tests, typecheck, `vite build`, and a manual browser run (create text/image, 4 recipients re-dividing live, multi-tab identity, End share by creator and rejection for others, phone layout).
- Changed the image split from a scattered tile collage to a grid: each recipient gets one solid block of the original (near-square cells, reading order from the top-left, every pixel owned once). Verified with 39 tests, typecheck, `vite build`, and a browser check of a 4-person image share.
- Fixed the Creator page getting stuck on "Dividing..." when the browser pauses animation frames (background tab, some in-app browsers): the shatter transition now finishes after 1.6 s even if no frame runs. Found while testing the live site.
- Added MP3 audio shares: upload (`POST /api/shares/audio`, 4 MiB), frame-accurate parsing that drops tags and the Xing frame, contiguous time segments per recipient in join order, per-recipient segment endpoint, cleanup of stored MP3s, an MP3 tab and audio player with a timeline bar in the UI. Applied the additive schema migration to the live Supabase database. Verified with 48 tests, typecheck, both builds, and a browser check that a real 22 s MP3 split 4 ways decodes to 5.5 s of audio per segment.
- Added MP4 video shares split into keyframe-aligned time segments: direct browser → Supabase Storage upload (up to 50 MB) with progress, MP4 keyframe parser, frame-exact ffmpeg stream-copy cuts cached in storage and served via signed URLs, MP4 tab and video player with a timeline bar, cleanup of originals, cuts and abandoned uploads. Applied the additive schema migration (video column, `pending_uploads`) to the live database. Verified with 56 tests, typecheck, both builds, and a local run against live Supabase (6 MB 720p clip uploaded directly, cut 6 s / 6 s / 3 s with exact frame counts, played in the browser).
- The first MP4 deploy (`05dc479`) crashed the Vercel function on load and took the whole API down for about 6 minutes; it was reverted (`c9a0937`). Likely cause: `ffmpeg-static` was loaded with `createRequire` at module load, which Vercel's bundler did not trace. Re-applied with the binary path resolved lazily (never at load) and `/api/health` reporting `video: true|false`; verified locally that the API still starts when the binary is missing.
- Added PDF shares split into contiguous page ranges: validated upload (4 MiB, encrypted PDFs rejected), per-recipient PDFs with only their pages, PDF tab and pdf.js page rendering (loaded on demand, renders without requestAnimationFrame), cleanup of stored PDFs. Unhandled API errors are now logged. Applied the additive schema migration (`pdf_page_count`) to the live database. Verified with 61 tests, typecheck, both builds, and a browser run where a creator's pages 1–4 of a 10-page PDF rendered with the right content.
- Raised the PDF limit to 50 MB: PDFs now use the direct browser → storage upload (shared with video, `pending_uploads.media_kind`), per-recipient PDFs are cached in storage and served via signed URLs, and pdf.js draws pages lazily as they scroll into view. Applied the additive migration to the live database. Verified with 63 tests (including a >5 MB PDF through the direct upload), typecheck and both builds.
- UI polish (2026-10-11): Windows XP-era fonts (Tahoma for text, Trebuchet MS for headings and title bars), the create button restyled as the green XP "start" button, shorter how-it-works lines, and no animation in the content/upload panel (static upload icon, instant tab switching). Checked in the browser; tests, typecheck and build pass.
